# Mapa de la Aplicación UniTask (Guía para la IA)

## Estructura de Navegación

1. **Dashboard (Panel de Control)**: 
   - Vista general.
   - Seguimiento de tareas activas.
   - Filtros por Sprint, Usuario y Prioridad.
   - **NO** se crean proyectos aquí.

2. **Proyectos (Gestión de Proyectos)**:
   - Aquí es donde se **crean, editan y gestionan** los proyectos y clientes.
   - Se pueden asignar colores y códigos (PRJ-XXX).

3. **Bitácora (Weekly Tracker)**:
   - El editor semanal para notas de reuniones.
   - Extracción automática de tareas con IA desde notas de texto o PDF.
   - Gestión de tareas semanales y migración de pendientes.

4. **Usuarios (Configuración)**:
   - Gestión de roles (Admin, PM, Consultor).
   - Aprobación de nuevos usuarios.
   - Generación de códigos de invitación.

## Conceptos Clave
- **Sprint**: Agrupación temporal de tareas.
- **Invitación**: Código necesario para que un nuevo usuario se registre.
- **Extracción AI**: Botón "Extraer tareas" en la Bitácora.
