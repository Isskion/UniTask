1. Perfil de Transpais (TSP) y Modelo Operativo

Transpais S.A. (TSP) es un operador logístico y de transporte de carga terrestre nacional e internacional. Su actividad principal consiste en proveer soluciones de transporte de mercancías bajo modalidades de carga completa (FTL), carga fraccionada (LTL), distribución intermodal (carretera + ferry/tren) y servicios especializados de arrastres y enganches de remolques.



1.1  Flujo comercial y modelo de subcontratación

La operación financiera se divide en dos grandes flujos: Ventas (facturación de ingresos a clientes) y Compras (liquidación de gastos a transportistas autónomos y filiales del grupo).

3.1  Tablas clave y su rol en el cálculo

Tabla

Ámbito

Rol y campos relevantes

dbo.Viaje

Entidad raíz

FechaCreacion (para PG1 en indexación de gasoil) y Estado (condiciones SQL de generación de guías).

dbo.Parada

Operacional

Vincula el viaje con cada pedido. Campos: Orden, Distancia (KM del tramo), IdTipoParada (1=Carga, 2=Descarga, 5=Puerto/Ferry), Costo (coste neto del ferry).

dbo.Pedido

Operacional

Pallets, Float1 (Metros Lineales), IdTransporte (qué transportista realiza la entrega).

dbo.Transporte

Operacional

ReferenciaExternaAdicional identifica filiales del grupo (valor 'FILIAL').

dbo.GuiaViaje

Puente financiero

Tabla puente IdViaje ↔ IdGuia. Clave para cruzar datos operativos con financieros en cálculos intercompany.

dbo.Guia

Financiero

Cabecera de la guía. IdTipoGuia determina si es venta (tg.Venta=1) o compra.

dbo.GuiaConceptoValorizado

Financiero

Catálogo

dbo.PrecioCombustible

Catálogo

  WHEN EXISTS (

    SELECT 1

    FROM dbo.Viaje v

6. Paso a Paso: Configuración de Tarifas en UNIGIS

Esta sección describe cómo configurar físicamente las tarifas de Transpais en la aplicación UNIGIS (módulo Fleet). El proceso cubre desde la creación de los conceptos económicos hasta la activación del cálculo automático en viajes reales.



PASO 1 — Acceso al Módulo de Tarifas



Ruta en UNIGIS: Fleet → Administración → Tarifas

El módulo de tarifas de UNIGIS se organiza en tres menús principales que deben configurarse en este orden:

Para qué se usa

PASO 4 — Configurar Bases de Cálculo SQL



Ruta: Fleet → Administración → Tarifas → Bases de Cálculo → Nueva

Las Bases de Cálculo (BC) son consultas SQL que devuelven un valor numérico al motor de cálculo de UNIGIS. El parámetro disponible es siempre @IdViaje. Pasos para crear una BC:



Paso

Campo

Descripción

1

Código

Nombre único de la BC (ej. Kms_Cargados). Sin espacios.

2

Descripción

Texto descriptivo de qué calcula la BC.

3

Consulta SQL

La query SQL completa. Debe devolver exactamente una columna y una fila con el valor numérico.

4

Tipo de resultado

Numérico (para KM, EUR, porcentajes) o Texto (para condiciones de tipo).

5

Introducir un @IdViaje real para validar que la BC devuelve el valor esperado antes de activarla.



Reglas importantes para las BC SQL:

- Siempre usar COALESCE(..., 0) o ISNULL(..., 0) para evitar NULLs que rompan el cálculo.

- Usar TOP 1 con ORDER BY cuando se busca un único registro (ej. precio de combustible).

- No usar cursores ni bucles. Solo SELECT estático referenciando @IdViaje.

- Las BC se comparten entre Tipos de Guía: una BC de KM cargados sirve tanto para compras de autónomos como para calcular suplementos de venta.

PASO 6 — Añadir Líneas con Fórmulas y Prioridades



Dentro del Cuadro Tarifario, pestaña Líneas / Fórmulas:

Función

Ejemplo Transpais

10

Tarifas especiales con condición (ej. cuadros Ball fijos).

PASO 7 — Configurar Escalados (Matrices)



Ruta: Fleet → Administración → Tarifas → Catálogos → Escalados

Los escalados permiten buscar un precio en una tabla según rangos de valores. Son imprescindibles para la tarifa LTL Sealed Air (PAL × ML) y para la distribución nacional por KG. Dos tipos:



Tipo de Escalado

Descripción

Aplicación Transpais

Escalado Simple (1 dimensión)

El sistema busca el tramo en el que cae el valor de una BC y devuelve el precio correspondiente.

Distribución nacional por KG: busca el tramo de peso y devuelve el precio por provincia.

Escalado Matricial (2 dimensiones)

El sistema cruza dos BC (ejes X e Y) para encontrar el valor en la intersección de la tabla.

LTL Sealed Air: eje X = BC Pallets_Transportado + Escalado_PAL; eje Y = BC Metros_Lineales_Transportado + Escalado_ML.



Para crear el escalado de la matriz PAL × ML de Sealed Air:

1. Crear Escalado_PAL: tramos 0—1,25 PAL | 1,26—2,5 PAL | 2,51—5,0 PAL | … | >16,25 PAL.

2. Crear Escalado_ML: tramos 0—0,5 ML | 0,51—1,0 ML | 1,01—1,5 ML | … | >6,5 ML.

3. En el Cuadro Tarifario, añadir una línea de tipo Matriz de Escalados vinculando ambos escalados y rellenar los valores en la cuadrícula resultante.

Ruta: Fleet → Administración → Tarifas → Catálogos → Tipos de Guía → [Editar] → Condición SQL

La Condición SQL de generación controla cuándo UNIGIS debe crear una guía de un Tipo de Guía concreto. Si no se configura, la guía se genera siempre. Para Transpais, las condiciones críticas son:



Tipo de Guía

Condición SQL

Lógica

CMP_INTERCOMPANY

Devuelve 1 si dbo.Transporte.ReferenciaExternaAdicional = 'FILIAL'

Solo genera guía de compra intercompany cuando el transportista es una filial del grupo.

CMP_INTERCOMPANY_BALL

Devuelve 1 si es FILIAL Y el cliente es BALL
